# タイトル(決めていない)

Unity 6で制作中の2Dスタイリッシュローグライクアクション

## 🚀 主な機能・特徴

* ダッシュやブリンクを駆使して敵の攻撃を避けながら部屋ごとの敵を殲滅していく
* 武器ごとに与えられたスキルを使って階層を攻略していく
* 敵を倒すとで手に入れたEXPをステータスに割り振り、自身を強化
